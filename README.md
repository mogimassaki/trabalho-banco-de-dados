# 🏨 Modelagem de Banco de Dados - Rede de Hotéis

Repositório destinado ao desenvolvimento do Trabalho Prático da disciplina de **Banco de Dados I**. O objetivo do projeto é mapear, modelar e construir uma base de dados voltada ao controle de hospedagem, utilização de serviços e consumo de hóspedes em uma rede hoteleira, além de integrar um sistema básico em Python com controle de transações.

---

## 🎯 Objetivos do Trabalho

O projeto é composto por 4 entregáveis obrigatórios:
1. **Modelo Conceitual:** Diagrama de Entidade-Relacionamento (DER).
2. **Modelo Lógico:** Estrutura das tabelas normalizadas com chaves primárias (PK) e estrangeiras (FK).
3. **Modelo Físico:** Script SQL (`.sql`) para criação do banco de dados e tabelas.
4. **Software em Python:** Aplicativo em terminal utilizando comandos de controle de transação (`commit` e `rollback`) para realizar operações de CRUD (Inserção, Consulta, Atualização e Exclusão) em pelo menos 2 ou 3 tabelas.

---

## 📂 Estrutura do Repositório

Para manter o nosso projeto organizado, utilizaremos a seguinte divisão de pastas:

*   📂 `documentos/` -> Enunciado oficial e documentações do projeto (contém o PDF inicial).
*   📂 `modelagem/` -> Arquivos e imagens do Modelo Conceitual e Modelo Lógico.
*   📂 `scripts_sql/` -> Arquivos `.sql` com as queries de criação do banco de dados e inserções iniciais.
*   📂 `app_python/` -> Código-fonte do software desenvolvido em Python.
